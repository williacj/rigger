ABOUTME: Measures Rigger's L1–L5, CLI and environment entry points against architecture boundary rule 4 for card 1151.

# Entry points beyond the substrate

## Measurement and method

This is a measurement of main commit 4f43b740fa3078a0913c9483d0dab39f6e145722, which follows the merge of #1146. The host was macOS with Node 26.5.0. The deterministic baseline at that commit passed 4,208 tests with zero failures. The searches below ran over that commit before any tracked edit. The throwaway probes used fixture files under TMPDIR and injected collaborators. They never wrote to a real forge, board or launchd job. Their complete source, command, commit and unfiltered output are on [the primary probe comment](https://github.com/williacj/rigger/issues/1151#issuecomment-6513440370), [the supplemental probe comment](https://github.com/williacj/rigger/issues/1151#issuecomment-6513467351), [the text probe comment](https://github.com/williacj/rigger/issues/1151#issuecomment-6513505005), [the gate and template comment](https://github.com/williacj/rigger/issues/1151#issuecomment-6513575386), [the print-site comment](https://github.com/williacj/rigger/issues/1151#issuecomment-6513626965), [the gate-number comment](https://github.com/williacj/rigger/issues/1151#issuecomment-6513668781), [the environment and admission-race comment](https://github.com/williacj/rigger/issues/1151#issuecomment-6513700158), and [the supplemental print-line comment](https://github.com/williacj/rigger/issues/1151#issuecomment-6513833568). The exact boundary clause used below is: “A contract allows any string where it names text, so text from outside stays any string inside. A verb that prints such text makes it printable where it prints it.” “Checked/plain”, “refused/built”, “unchecked”, “thrown/unbuilt” and “other” in the maps mean, respectively, the five behaviors named in the card. C means conforms and B breaches. A code citation gives the deciding check; P/Q/T citations give the probe command and full output. Where a map says text is unchecked/C, it relies on the quoted any-string clause and the fact that the parsed value is still plain data.
