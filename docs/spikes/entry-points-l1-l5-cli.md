# Entry points beyond the substrate

## Measurement and method

This is a measurement of main commit 4f43b740fa3078a0913c9483d0dab39f6e145722, which follows the merge of #1146. The host was macOS with Node 26.5.0. The deterministic baseline at that commit passed 4,208 tests with zero failures. The searches below ran over that commit before any tracked edit. The throwaway probes used fixture files under TMPDIR and injected collaborators. They never wrote to a real forge, board or launchd job. The exact boundary clause used below is: “A contract allows any string where it names text, so text from outside stays any string inside. A verb that prints such text makes it printable where it prints it.” “Checked/plain”, “refused/built”, “unchecked”, “thrown/unbuilt” and “other” in the maps mean, respectively, the five behaviors named in the card. C means conforms and B breaches. A code citation gives the deciding check; P/Q/T citations give the probe command and full output. Where a map says text is unchecked/C, it relies on the quoted any-string clause and the fact that the parsed value is still plain data.
