# Kind judge lists match the panels

The `change` kind now names `reviewer` and `architect`, each on the provider opposite the maker, which is the panel C23 has run since P42. `roles.pm` maps `maker:codex` to `codex`, so a Codex-made `spec` card is now panelled with Claude judges (C36 item 3).

`test/gate-check.test.mjs` imports the live config, so its fixtures broke as soon as `change` named a second judge. That is how the pre-dispatch attack found that the card's grant classes were short. One fixture also declared a `permissions` map. Under that map the fake answers 404 for any author it does not name, so the added architect marker counted only once its author was given `write`. All of these lines were granted in one round before any push.

The gate reads the config from the default branch. A green `rigger/gate` status posted before this merge therefore stays on its head until another event runs the gate. The pull request lists the open `change` pull requests that the new list reaches.
