# Card #997: doctor reads a loaded launchd job

Doctor reads a loaded job through L0 and checks its real program path and exit timeout. The
config module owns the cleanup bound and concurrency default. The scheduler imports that
same default. Doctor reports every applicable fault, escapes controls in paths, and omits an
absent job. The README, help summary and troubleshooting table name the check last.

The PM resolved the package-layout ambiguity in acceptance revision `fa7481d498e1`, after
[the maker's escalation](https://github.com/williacj/rigger/issues/997#issuecomment-6431688827).
A scoped package at node_modules/@williacj/rigger qualifies; an unscoped alias does not. The
program must resolve outside the target and outside any directory named _npx.
