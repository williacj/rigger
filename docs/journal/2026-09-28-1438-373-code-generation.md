# #373 — No module under `src/` runs code it builds at run time

## What was built

- `test/layer-boundaries.mjs` gained the code-generation rule, beside the dynamic-import rule and
  shaped like it. `GENERATORS` lists `eval`, `Function` and `constructor`, refused wherever a module
  names one as a value or as a fixed string. `GENERATOR_MODULES` lists `node:vm` and `vm`, refused
  as a static import, a re-export, a star export or a dynamic `import()` whose specifier the source
  fixes.
- A name that only keys an object literal or a class member reads nothing and passes, as the
  loaders' names do, so a class may still declare its own `constructor`.
- A dynamic `import()` of `vm` is reported under the new rule in place of the dynamic-import rule,
  so the message names why it is refused.

## What we learned

- **`constructor` is the route that spells no other name.** Every function reaches the `Function`
  constructor as `.constructor`, and an async or generator function reaches its own kind of it,
  which no global names. Refusing `Function` alone leaves `(async () => {}).constructor(code)` open.
  Refusing the name `constructor` closes that and also the destructured
  `const { constructor: build } = fn`. It costs `src/` nothing: at `d3da69f`, `grep -rn constructor
  src/` finds it only in two comments.
- **The limit is the loaders' limit.** A key the source does not fix — computed from a variable,
  decoded, or taken by enumerating a prototype's own properties — is out of this reader's sight for
  `constructor` exactly as it is for `mainModule`. That is a review finding, as the reader's comment
  says, not something a name-reader can close.
- **Mutations shown to discriminate.** Each mutation had its anchor found once, was read back off
  disk, and was run on `test/layer-boundaries.test.mjs`'s 93 tests at `7508e05`. The file was then
  restored byte-exact against `HEAD`. Each reddened one test:
  - `eval` dropped from `GENERATORS`: the eval test.
  - `Function` dropped: the Function-constructor test.
  - `constructor` dropped: the Function-constructor test.
  - The key exemption dropped: the test that a class's own constructor passes, on
    `export class Card { constructor(id) { … } }`.
  - The dynamic `import()` of `vm` not refused under the rule: the `vm` test.
  - The static import of `vm` not refused: the `vm` test.
