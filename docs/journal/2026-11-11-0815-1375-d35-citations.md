The card's measured list omitted `docs/spec/requirements.md` L478. Its text cell cites `D25`

`src/scheduling/admission.mjs` L59 now names `.github/scripts/gate-closure.mjs` as what measures
the gate's import closure, since `AGENTS.md`'s "Self-hosting" no longer lists it (P2).

`test/gate-closure.test.mjs` gains three tests. One asserts the check's pin in
`.github/workflows/self-hosting.yml` is an ancestor of `HEAD`. Another measures the check's
import closure in the tree at that pin and admits no bare import, no CommonJS call, and only
`src/cli/doctor.mjs`'s config import. Both pass at #1373's merge, so the owner's M8-U13 admits
them without a red run; the pull request quotes each failing against a deliberate break.

The third, the pin-reader matrix test, holds the reader both use. Round 1's judges found the first
reader accepted only two-space indentation and single quotes. Round 2's found the second still
needed an unquoted key. Either way, an equivalent workflow failed both tests before either checked
its invariant.

An independent attacker then found values the reader returned that a YAML parser reads differently.
Its examples were a plain value continued on a deeper line, and a no-break space before `#`.

The reader now returns only a value the workflow holds. It reads the top-level `env` block mapping's
`SELF_HOSTING_COMMIT` key and value plain, single- or double-quoted, with YAML's escapes. It reads
them at any indentation, around blank lines and comments, after a byte-order mark at the very start,
and with CRLF line ends. It takes white space as the space and the tab only. It skips every other
key's value, including a block scalar, or a quoted scalar or flow collection running past its line,
so a value never reads as a key.

It refuses by name, as `unsupported YAML form for SELF_HOSTING_COMMIT: <form>`, every other form:
- for the `env` map or its keys: a flow mapping, an anchor, an alias, a tag, a merge key, a sequence,
  or a second document;
- for the pin: a block scalar, a value continued on a deeper line, a value on the next line, or a
  value that is not 40 lowercase hex characters;
- for the file: lone CR line ends.

The matrix test holds each equivalent spelling to the same commit, each other form to its named
error, and a workflow with zero pins or with two to a refusal.
