ABOUTME: Why #1441 allows terminal escape bytes on the raw diff read and keeps the fake's refusal route.

# Read the whole raw diff

[Card #1441](https://github.com/williacj/rigger/issues/1441), acceptance revision
`038e472b46ae`, records gh 2.103.3's refusal of a raw response holding ESC. The diff
read requests escape output explicitly. The read runner admits that flag only after
the diff media-type header. Other read forms keep their existing arguments.

The shared fake models the observed refusal, including an ESC at any position and
empty stdout. Its flagged route shares the same diff and HTTP-error handling. The
unflagged route remains in its inventory to model gh's refusal. The adapter's
inventory test separately forbids issuing that route, as grant G4 requires.

The controlled regression failed before the fake changed, and the adapter regression
then failed with gh's refusal before the production read changed. The consumer
checks exercise both judges' evidence and the self-hosting check through that shared
fake. A local proxy supplies a non-JSON ESC diff to real gh and checks the default
transport against the served bytes. Only the judge-evidence check claims R-EVIDENCE-3.

The self-hosting regression gives its check process Node's mocked timers before
the check loads L0. A checkpoint proves that setup ran. Its fake-gh children keep
their existing entry behavior. The real-gh host proof retains the real transport.

The first deterministic baseline failed during high host load. Its one retry used
the quieter start guard and retained only the real-wait failure covered by #1317; the dispatch
permits work to continue in that state. The PR retains both outputs and the final
hook, fresh-clone, host and mutation evidence. The `uptime` start probe in
`1441-self-hosting-green.log`, on this card's working tree, measured load 24.14.
That run is excluded from credited verification; its output is retained.

Taking effect follows the card's scope edges: the installed engine and the pinned
self-hosting check need their separate promotion steps.
