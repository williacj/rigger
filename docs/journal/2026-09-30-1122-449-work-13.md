# #449 — R-WORK-13 to R-WORK-16 in place of R-WORK-11

**"A workspace of the repository" was wider than it read.** Git counts every linked worktree as a
workspace of the repository, so `R-WORK-11` let Rigger replace an owner's worktree on another
branch, uncommitted files and all. The engineer judge measured both cases on PR #448 (flag 2,
j448-8). Rigger keeps no record of what it made (`A6`), so only git can tell its workspace from
someone else's. Ruling 9 drew the line at the card's own branch, and the owner chose it (`Q9-1`).

**The narrowing takes new ids.** It changes what must be true of Rigger: a worktree on another
line of work was replaceable and now is not. Under the preamble of `docs/spec/requirements.md`,
that withdraws `R-WORK-11` and allocates new ids, starting at `R-WORK-13`, the next the group has
never used.

**Three conditions in prose hid a fourth case.** The first draft put the conditions in one row's
sentences. The architect judge on PR #452 found that the prose left the handed checkout on the
card's own line of work unaddressed: a build that neither replaced it nor failed the attempt met
every sentence. A lead row with one continuation row per condition, shaped like `R-GATE-4`, closes
that.

**A plainer word was a broader one.** The second draft swapped git's "linked worktree" for "a
checkout of the repository". All three judges on PR #452 found that broader than ruling 9: the
main worktree, when Rigger was not handed it, and a separate clone of the repository each met it.
The rows now say "a worktree added to the repository", and exclude its main worktree by name. A
word chosen to keep a mechanism out of a row still has to be tested against every case the
ruling refused.

**Ten tests declare nothing for a while.** The matrix check refuses a test that declares a
withdrawn id, and no test may claim the new rows before the build meets them. So the ten
`// proves R-WORK-11` lines go now, under the owner's grant on #449, and #450 (M3-05b)
re-declares each test against the row it proves once its code makes the rows true. Until then the
matrix lists `R-WORK-13` to `R-WORK-16` as gaps.
