# Card 875: R-FAIL-6 classes three causes

[#875](https://github.com/williacj/rigger/issues/875) proposes the delta U29 and U30 rule on.
`R-FAIL-5`'s table classed three causes nowhere: a derived branch name git refuses, a worktree
root that is not absolute, and the maker's scratch directory not made because the file system
gave no answer. The architect's attacks on #870 and #871 found them.

The register's preamble decides the id: editing the table to move a cell into scope changes what
must be true. The widened host row brings a cause into the hold, so the row takes `R-FAIL-6` and
`R-FAIL-5` moves, with its table unchanged, to the retired register.

What taught us: a citation to a dimensions table's heading sits inside its own row. A script that
looked for the heading by its text found the row's citation first, and an assertion caught it
before anything was written. Find a heading by its line start, never by its text alone.
