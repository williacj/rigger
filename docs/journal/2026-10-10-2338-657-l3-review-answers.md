# A move is work even when no maker starts

L3 formerly ended a test drive when a pull started no maker. Once L3 carried Review to Owner, that condition could stop a drive while a board move had just completed. The drive now continues until a pull answers nothing and starts no maker.

The first pass reserved a `merge` card without occupying a slot. At concurrency one, that reservation spent the pull limit and starved a Ready card behind it. L3 now leaves `merge` without a claim or pull event; M5-09 owns that lane. Other review answers hold a claim and slot until L2's write settles. A refused pull event still needs to release both, or it strands capacity for a later pull.

The fake repository now reads a pull request's head from its local origin when one is supplied. This lets a continuing maker's pushed commit become the next forge fact without changing the fixture's in-memory default. The marker fixtures used by this card share one constructor so a later marker field has one place to enter these tests.

The Owner-to-Review once fixture initially returned to a branch spelled `main`. CI's fresh repository used a different initial branch, so that fixture failed before reaching the behavior it meant to prove. It now reads the initial symbolic branch and returns to that branch after seeding the pull request; the continuing fixture follows the same rule.
