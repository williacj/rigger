# Claude session path audit

Round-two review found `~/.claude/session-env/<session_id>/` surviving the live judge test. The earlier teardown looked only under the test's encoded `projects/` directory. A red live probe reproduced the missed directory and removed its own session path after the assertion.

The revised live test inventories `~/.claude/` before the session, immediately before cleanup, and after cleanup. It prints the session id, removes only newly added paths named by that id or the test's unique working-directory project path, and asserts all selected paths are absent. It reports every other new path with its birth time without deleting or attributing it.

In two measured runs, a timestamped backup appeared under `~/.claude/backups/` during the session. Its name had neither the session id nor the working-directory name. Item 12's final ruling leaves such paths for #629 to confine and requires this card to report them without assigning an owner.
