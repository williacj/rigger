# #1058 — placing the telemetry push

The delta adds "Pushing the stream" under "Telemetry", a push side beside the forge adapter's four
in boundary rule 2, and a sentence each in "Telemetry" and "Supervising `run`" saying exit cleanup
makes no push. The L5 row and the Engine settings row name the push.

The sources it builds on:

- the architect's r1 review on #1009, S9 (1009#6433591635): the push is L5's, through a fifth L0
  side admitting one write, outside `read.mjs`, pushed at a verb's normal return and never in exit
  cleanup;
- the r2 review, §1 (1009#6434658018): L5 also pushes at each drain trigger;
- `R-RECORD-13` to `R-RECORD-18` and the `### R-RECORD-13 — Push states` table;
- the M7-03 report, `docs/spikes/telemetry-push.md`, for every figure and every claim about git and
  the forge that is not marked a judgment.

What I chose that no source fixed:

- **The drain does not wait on the push, and one push runs at a time.** A drain during an in-flight
  push makes one follow-up push once it settles. This is what lets the r2 review's reversal be ruled
  unmet whatever `poll` is: a slow push delays the copy, never work. The report's own premise, a
  poll in tens of seconds, then carries nothing.
- **The parent comes from the forge.** Each push reads the tip with `git ls-remote` and fetches it
  where the object store lacks it. That keeps `.rigger/` at its three things and writes no local
  ref. The report measured neither the fetch without a destination nor stdin to `hash-object`, so
  both are marked judgments.
- **`push.end` is L5's event**, and the push side's `git` calls record no `call.end`. The L0
  substrate fault rate then counts no push, which I think right: a refused push is no host fault.
- **`PUSH_TIMEOUT` is 30,000 ms**, about nine times the slowest whole push measured (3.420 s). It
  is a judgment, and no timeout was measured.
- **A drain that ends `run` makes no push of its own.** The return's push follows at once.

Left for others: the layer map gains no edge for L3 having L5 push, because "The layer map" is not
in the card's Lands in, and #1050 added no L5 edge for the report either. A later structure card can
draw both.
