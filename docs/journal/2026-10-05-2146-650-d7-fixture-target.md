# #650 — a fixture clone can be the exit run's target

`D7` rule 4 named one target for an exit run: a separate clone of the commit under test. M5's
exit list runs against a fixture, so M5-14 could not meet the ratified rule as written. The
amendment was first planned for M5-02, but M5-02 stays open until go-live, after M5-14 runs.
Codex's check of decomposition revision 2 caught that ordering, and the owner's ruling P9 moved
the amendment to its own card, merged before M5-14.

The amendment adds a sentence to rule 4 and leaves its three parts as they were. Only the target
gains a second form; the tarball and worktree-root parts still bind the fixture run. The notes
argue why this keeps the installation rule's separation, and name the one observation that
reverses it: an exit run against a fixture clone that changes a file or a ref in this repository.

The status line now carries two amendment dates. The preamble says an amendment adds its date
after `Ratified`, and no entry carried two before, so the form `Amended 2026-10-01 and
2026-10-05` is a first use.
