# #1040 — L0's call events and the substrate fault rate

At `6b31ca74`, "Telemetry" gave L0 no section, because no forge or git call recorded its own
latency or outcome. The r1 review on #1009 (1009#6433591635) found that as S5. Outline r2's M7-08
row (1009#6434572290) gave the L0 call events a structure card of their own. The r2 review's M7-08
row (1009#6434658018) filed it after M7-01, because both edit "Telemetry". Outline r3's M7-08 row
(1009#6440375653), ratified by M7-U3 item 4, is "L0 call events (S5): forge calls in `throughL0`,
git calls in `worktrees.mjs`; the fault rate per system; the cell where the gate's sink refuses an
event".

The placement is the card's, from the attack on it (1040#6449963010): emission in `throughL0` and
in `worktrees.mjs`'s `call` alone, nothing for git calls through `doctor.mjs`'s `asked`, and the
gate's sink left unnamed so it never refuses a call event.

Choices the card left to the maker, each a judgment on the code at `6b31ca74`:

- **One event, `call.end`,** with `system`, then `side` on a forge call or `operation` on a git
  call. The fault rate reads only `system` and `outcome`.
- **A command that never started records `failed`.** That keeps the card's three outcomes. A
  missing `gh` or `git` is a fault of the host, so it counts.
- **A lost fetch race counts as a fault,** and `fetch.retried` stays as it is. Leaving it out would
  have the derivation read a second event for one cell.
- **A refused `call.end` rejects the call with `EVENT_REFUSED`,** as a refused kill already does,
  because the call has acted outside Rigger by then.
- **The Codex skill probe records nothing,** as the attack recommended. Its failure already reaches
  L2 naming the probe, so the first reversal excludes it by name.

What the card's fixed placement costs: a non-zero exit that its caller reads as an answer, as `git
ls-remote --exit-code` gives for a missing ref, counts as a fault. The delta names that as a
reversal instead of changing what the card fixed.
