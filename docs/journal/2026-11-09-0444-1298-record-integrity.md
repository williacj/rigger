## Case ledger

The new tests ran against unchanged merge-base production code through the suite slot. The
record-integrity file reported pass 3 and fail 1: R14 refused a partial tail at line 2.
The named once/push guards reported pass 4 and fail 0. The host file reported pass 34 and fail 0.
The guarded I4 base run reported pass 1 and fail 1. Both emit windows overlapped at both line
sizes. The 200-byte stream held 400000 bytes and read back every event. The 1 MiB stream held
2097152000 bytes, but the reader failed with `Cannot create a string longer than 0x1fffffe8
characters`. The guard restored the maker's R14 source preimage byte for byte afterwards.

The reader now scans newline boundaries in the file buffer and decodes one complete line at a
time. It preserves E1 without requiring a JavaScript string as large as the whole stream.
The writer and push implementation are unchanged.

With that reader change, the same named deterministic file reported tests 4, pass 4, fail 0,
and the full event-sink host file reported tests 40, pass 40, fail 0, skipped 0. Their combined
run's one-minute load was 6.99 to 6.23, with 631 user-process lines at start. The large concurrent
stream held 2097152000 bytes and returned every event; both children's measured emit windows
overlapped. The full once and drain-push files reported tests 121, pass 121, fail 0, skipped 0,
with one-minute load 5.89 to 4.73 and 627 user-process lines at start. These are measurements
from the suite-slot runs `green-reader.log` and `affected-once-push.log`, at the stated base
HEAD with this work's uncommitted source and tests.

The existing test-line changes are event-sink's base lines 178–180 and 186 under grant class 2.
The inserted R6 declaration uses grant class 1. The remaining test changes are additions.
New deterministic tests inject `manualClock` wherever they read time. Host children record
their PIDs before the parent can signal them; their synchronization files live outside the state
directory. No source writer gains a state path.
