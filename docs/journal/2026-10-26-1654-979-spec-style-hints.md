# Card 979: advisory spec-style hints for rules 4 and 5

The card follows U75, which puts a change to how makers and judges work into the repository's
own checks, and U77, which runs the Rounds set on the Mac mini. Rules 4 and 5 stay judgments.
A hint points at a sentence an author should reread before a judge does, and nothing reads a
hint to decide an exit.

`hints(text)` sits beside `findings` in `scripts/spec-style-lint.mjs`. It reads the same prose
paragraphs and table cells, through the same fence-blanking and sentence splitter, so a list item
and fenced code give no hint. `check(root)` returns the hints beside the findings, and only the
findings set `failing`. `--hints` prints them after the summary. Without it, the lint prints what
it printed before byte for byte, which the pull request shows by running the merge base's script
on the head's tree.

The thresholds are the card's: three `then` in a sentence, or three of `where`, `if` and
`unless`. A `D#`, an `R-` id or a backticked path, beside one double-quoted run of eight words,
is a rule 5 hint. A sentence can draw both. The card scoped list items out for rule 4 and said
nothing for rule 5. The rule 5 hint reads the same paragraphs and cells, because one reader for
both hints is the smaller thing.

Over the four binding documents at the head, `--hints` prints no hint. No sentence there holds
more than two `then` or more than two conditions, which is what the 40-word ceiling would predict.

The new tests went into the two existing test files rather than a new one. A new file would need
a line in `test/suite-tiers.test.mjs` and `test/suite.sh`, and the card changes no existing line
under `test/`.

Four tests were written after the code they pin: the list-item, fenced-code, usage and
retired-register tests. Each was then run against the merge base's two scripts, with only the
test file's `hints` import line dropped, since the base exports no `hints`.

- The usage test went red on its exit assertion, 1 where it expects 2, because the base reads
  `--hint` as a root path.
- The retired-register test went red on its exit assertion, 1 where it expects 0, because the
  base reads `--hints` as a root path. That red shows the option missing, not the retired
  register's exclusion, which mutation M3 shows.
- The list-item and fenced-code tests failed with `ReferenceError: hints is not defined` and
  reached no assertion. That is no red. They have no test-first evidence, only mutations M1 and
  M2, and the coordinator was told. The owner excused those two once, under U82.

Both round-1 judges found that a list item wrapping onto an indented line drew a rule 4 hint.
`paragraphs` trims indentation, so it opens a paragraph on the continuation. A test of a wrapped
item, run before the fix at 18:51, went red with one rule 4 hint on the continuation line. The
hints now skip a paragraph that starts on an indented line inside a list item. `paragraphs` is
unchanged, so the findings are too.

Round 2's judges found that rule wrong both ways. An unindented line straight after an item is
CommonMark's lazy continuation, and it was hinted. A line after a blank indented one space is
prose outside the list, and it went unhinted. The hints now follow CommonMark's extent.

- With no blank line between, a line goes on with the item, indented or not.
- After a blank line, a line stays in an item only when indented to its content column.
- A line indented less ends every item it falls short of, nested ones included.

Four tests were written first, at 19:16, using the judges' probes. Three went red on their
assertions: the lazy line, the prose indented short, and the nested list. The fourth, a paragraph
indented to the content after a blank, was green, because round 2 already held that case. A
mutation that stops any line continuing after a blank reds it.

Round 3's judges found that rule still short. Only a paragraph takes a lazy line, so prose after
`- # Heading` was suppressed. A thematic break ends a list with no blank line, and a tab was
counted as one column. Under U83 the owner granted this fourth round to finish the list rules.
`listContinuations` now walks CommonMark 0.31.2's list-item and block-structure sections.

- Tabs run to the next multiple of four columns.
- The content column is the marker plus up to four columns after it, and one column past the
  marker where more follow.
- A heading, a setext underline, a thematic break, a block quote, a table row, a fenced-code
  opener and an HTML block that can interrupt a paragraph are never lazy lines. Each ends an item
  it is indented short of.
- A lone HTML tag cannot interrupt a paragraph, so it stays lazy text.
- Fence content indented short of an item ends it.
- A marker indented four columns past its container is code.
- An empty item ends at a blank line.

The hints now blank each line of list text and read the paragraphs left, rather than dropping
the paragraphs that start on one. A paragraph after a list therefore reads on its own, even
where the shared reader would have joined it to the item. `unfenced` gained an optional record
of where each fence opens, and its return value is unchanged.

The tests came first, at 21:28, with both judges' probes. Seven went red on their assertions.
The block-quote and empty-item tests were green, because the round-3 code already held those
cases. Three more cases came out of the sweep: setext `===`, the four-column limit and fence
content. Each test was written before its code and run red, at 21:30, 21:31 and 21:32. Sixteen
guarded mutations each red a named test, and the two that first survived exposed a test that
did not discriminate and a missing case.

What taught us: a list extent rule needs the spec's whole list of interruptions at once. Each
round that fixed only the probe it was shown left the next probe standing.

The skill's "Not all of it lintable" bullet gained one sentence. `npm run budget:instructions`
measured 14,916 live words at the first merge base `ac3df94c` and 14,933 at its head. After
merging `main` at `383f16e9`, it measured 15,027 at that merge base and 15,044 at the head. Either
way, the card adds 17 words against its cap of 30.

What taught us: a hint that shares the lint's reader inherits its disclosed biases for free. A
merged sentence can draw a hint it should not, and a split one can hide one.
