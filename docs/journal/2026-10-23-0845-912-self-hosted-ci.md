# Self-hosted CI on the Mac runner

Card #912 follows U33–U36 and K64 on [M6 record #740](https://github.com/williacj/rigger/issues/740#issuecomment-6364112722), and U37 on [the same record](https://github.com/williacj/rigger/issues/740#issuecomment-6366048856). The `check` and `demo` jobs select `CJs-MacBook-Pro` through its `self-hosted`, `macOS` and `ARM64` labels. Node 26 is the declared floor and the CI major.

The host suite uses the hosted image key only when both `ImageOS` and `ImageVersion` are non-empty. Otherwise it reads the local OS, release and architecture, so this runner's CI and local runs share one host key.

[The draft on #912](https://github.com/williacj/rigger/issues/912#issuecomment-6366291975) gives the owner two calls: one sets fork pull request approval to `all_external_contributors`; the other requires `check (26)`, `rigger/gate` and `self-hosting` in ruleset `23968611` with their integration pins. The owner applies the ruleset call before this pull request merges, and #914 merges afterward.
