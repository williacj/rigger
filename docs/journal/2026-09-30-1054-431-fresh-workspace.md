# #431 — A fresh workspace, and a check that git's refusals hid

**L1 asks, then acts.** `src/execution/workspace.mjs` derives a card's workspace and branch from
the topic. It asks L0 whether git accepts the branch. Where anything is at the path, it asks L0
whether that is a linked worktree of the repository. Only then does it remove the old workspace
and have L0 make a fresh one from the main line. The handle a verb builds asks git about card 1's
topic before anything else (ruling 6, Q-B).

**The outcome tests did not need the check.** The first guarded mutation deleted the worktree
check, and 26 of 27 tests stayed green. Git's `worktree remove --force` refuses each foreign case
by itself:

- a plain directory fails validation, because its `.git` does not exist;
- another repository's worktree fails the same way;
- the main working tree is refused as a main working tree.

So each attempt still failed naming its path, and every file and branch stayed as it was. Only the
failure's wording changed. `R-WORK-11` and ruling 7 rest on L1 asking before any git call that
could write, not on git refusing. A test now puts a recording `git` first on `PATH` and finds only
questions sent for all three cases. With the check deleted, it goes red.

**A symbolic link is replaced as a link.** Where the workspace path is a link to a worktree of the
repository, L1 removes the worktree at the link's real path, then the dangling link, then makes the
fresh workspace at the path itself. That keeps the workspace directly under the root (A9).

**Found outside the acceptance, and not built:**

- A topic of `@{-{number}}` passes `validate`. Card 1 then derives `@{-1}`, which
  `git check-ref-format --branch` accepts by expanding it to the previous branch. The engineer
  judge on #445 measured `worktree add -B '@{-1}'` resetting that branch.
- Suppose the engine runs from a linked worktree of the repository, and a derived path is that
  worktree. L0 answers yes, so L1 would replace the engine's own checkout. Only the main working
  tree is refused.
- A link at one card's path pointing at another card's workspace is replaced as a worktree of the
  repository. The other card's workspace goes with it.
