# Card 871: failures at the attempt boundary

U29 classifies three sets of causes in `R-FAIL-6`. An answered workspace or maker scratch replace-rule refusal, and a card branch checked out elsewhere, belong to the card. A moved or deleted forge line, a derived branch name git refuses, and a root that is not absolute are out of the retry rule. A check or make that gives no answer remains a host failure, as does a continuing forge read or fetch that fails. The maker's unanswered scratch check has the same host way as a dispatch that never started.

K56 gives L2 `card-local` and `out` beside its existing `environment` class. L0 tags a continuing line's moved, deleted and failed-forge causes where it reads git's answer. L1 maps those tags to reports without reading the error's wording. It also identifies answered replace-rule refusals where it owns those checks. L2 stops a card-local or out cause on the attempt that meets it. A failed fetch has its own host code, so it cannot pair with another workspace host failure to hold a card.

K51 makes `stop` the interim answer for a card-local refusal. L3 already excludes a card whose stop carries `attemptFailures` from another pull in that invocation. M6-16 owns the later escalation; this change claims none.
