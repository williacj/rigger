# New tests are held to suite health

The owner directed on 2026-10-29
([740#6497180994](https://github.com/williacj/rigger/issues/740#issuecomment-6497180994)): "I
want to stop bad tests before we get buried in debt." The architect's ruling at
[740#6497153704](https://github.com/williacj/rigger/issues/740#issuecomment-6497153704) set the
scope and the budget rule: the bars go into the skills as text, with no mechanical check, and the
live `.claude/` pool does not grow.

This change writes the card's pinned text P1 to P7 into the three skills and their templates.
The maker checks each added test against the `tdd` skill's seven classes, the judge probes each
class under `code-review`, and the author asks for proof by dimension rather than a test per cell
under `acceptance`.

The pinned text cost 619 words, measured with `node scripts/instruction-budget.mjs` at base
`e20bd768` on 2026-10-29: 15,919 against a budget of 15,300. The card's own measure, 574 at
`2e264070`, predates #1135. The words came from the `tdd` skill's scan-shape prose and tables,
678 words by `wc -w` at the same base. Every row of them is in the block comment above
`declarationsIn` in `scripts/build-test-matrix.mjs`, which the skill already said governs. A
three-line pointer to that comment replaces them.

The card first pinned the removal of "Record that source where the double is defined." from the
`tdd` skill, saying class 4 carried it. PR #1147's reviewer found that class 4 binds only the
tests a change adds, while the sentence binds every double
([1147#6506382669](https://github.com/williacj/rigger/pull/1147#issuecomment-6506382669)). The
author withdrew that removal, and the sentence stays. With it restored, the pool is 15,284.
