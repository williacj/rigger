# Starter assets condition the npm commands a fresh consumer lacks

The host tests in `test/package.test.mjs` (rows K1 and K2) install the packed head and run
`rigger init` into a scratch repository with no `package.json` and into one whose
`package.json` holds only a name and a version. At the merge base `52fb8a3d` both reported the
same seven commands, each neither defined there nor conditioned:

| Forked file | Command | Resolution |
|---|---|---|
| `.claude/agents/engineer.md` | `npm run preflight -- <card>` | bold lead-in "Preflight, where the repository defines it." on its list item |
| `.claude/agents/engineer.md` | `npm test` | "where the repository defines it" after the command in "Batch test-line grants" |
| `.claude/skills/acceptance/SKILL.md` | `npm run check:card` | item 23 opens "Where the repository defines them" |
| `.claude/skills/acceptance/SKILL.md` | `npm run preflight -- --body-file <body-file>` | the same item 23 |
| `.claude/skills/tdd/SKILL.md` | `npm run mutation:receipt` | the sentence opens "Where the repository defines it" |
| `.claude/skills/tdd/SKILL.md` | `npm run matrix` | the declaration paragraph's sentence opens "Where the repository defines them" |
| `.claude/skills/tdd/SKILL.md` | `npm run matrix:check` | the same sentence |

`node --test` and `node --check` were already defined: `node` is on PATH for every consumer
(`README.md`, "Prerequisites").

The live instruction pool stood at its 15300-word budget, so the conditioning had to be word
neutral. The conditioning cost 26 words across five passages (counted with `wc -w` per file at
`52fb8a3d` and at the head: engineer +11, acceptance -7, tdd -4). The same number came back from
words that carried nothing: the acceptance skill's restated refusal-reasons sentence became
"refuses only", item 23 and the matrix sentence were tightened, and "before you <verb>" clauses
became gerunds. `npm run budget:instructions` reports 15300
at both ends (measured with that script at `52fb8a3d` and at the head). The templates and this
repository's `.claude/` copies stay byte-equal, as the init self-comparison requires.
