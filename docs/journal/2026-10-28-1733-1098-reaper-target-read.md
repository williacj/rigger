# #1098 — Observe completed targeted ending reads

At source base `c3531ead6b30fab65a0a3f0b759449c708883c3e`, `test/suite-reaper` made ending decisions from a targeted `/bin/ps` result and a signal-zero check but did not retain the result's safe structure for the outer E5/E6 fixture. This diagnostic adds one bounded structural record per completed targeted read when the fixture supplies an owned writable trace under its temporary directory. It does not change the confirmed-ending return, throw, deadline, assertion, or cleanup path.

The projection records a fixed case cell, PID and read sequence; fixed parser, signal-zero, status, signal, and error classes; decoded stdout/stderr UTF-16 lengths; row and separator counts; at most 64 separator positions and kinds; and at most 256 stdout code units as character classes. It excludes raw command text, paths, stdout, stderr, and error messages. The outer fixture validates each line before publishing it, assigns its 1-based read sequence from line order, drops unrecognized fields, and calls missing, truncated, invalid, unreadable, or refused traces `incomplete`. Its existing ending assertion remains the oracle.
