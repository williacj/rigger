# #333 — deltas H1 to H5 placed in `ARCHITECTURE.md`

## What ran

The deltas are the architect's ruling 3 §7 for H1 and H5, and ruling 2 §10 for H2 to H4, both
archived on #332. The owner ratified them with the M2 decomposition at revision 5b. Each was
placed at the anchor its ruling names, at base `8393e7d`.

A throwaway script compared every quoted paragraph of those two sections with the edited file,
whitespace-normalised. Every paragraph appeared verbatim, and each replaced sentence was gone.

## What we learned

- Three anchors sit mid-paragraph: H2's two replacements, and H4 and H5 in Telemetry's first
  paragraph. Inserting there inline would have made each paragraph state several things, against
  `AGENTS.md`, "Write to be acted on". So the edit adds paragraph breaks at the anchors. It keeps
  the order of every sentence, so the breaks are form, not meaning.
- Telemetry's later paragraph still opens "The sink appends each event synchronously." Under H5 a
  sink that has no state directory yet holds an event rather than appending it. Ruling 2 §2 says a
  held event is not an append, so the two read consistently, but only with that ruling in hand.
  The sentence is outside #333's acceptance, and the pull request names it for the owner.
