# L0 call events, card 1047

The card's acceptance revision is `f2729057fa33`, measured with `gh issue view 1047 --json body -q .body | shasum -a 256` on 2026-10-28. The implementation follows `ARCHITECTURE.md`, “L0's call events”. It changes neither that contract nor the process adapter.

`throughL0` records the sending runner's side. A write runner's prerequisite read still goes through the read runner. The workspace adapter records inside its queue, after the command settles and before any fetch retry. Normal results retain their existing caller-facing shape. A refused end carries the process adapter's raw result, or the original startup refusal as its cause. A refused kill keeps its failure and gains the end among its unrecorded events when that append also fails.

The owner marker required for this change covers Self-hosting code in the forge runners, workspace adapter and test runner's host-file list. It does not ratify a contract change. The card's reviewer and architect are separate Codex judges; the maker supplies no verdict or marker.
