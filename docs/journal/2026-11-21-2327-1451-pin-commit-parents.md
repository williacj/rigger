The pin assertion now uses HEAD and every commit in the worktree-specific MERGE_HEAD. The
shared git fixture resolves that file through git, so linked worktrees use their own merge
record. A squash, cherry-pick or rebase contributes no additional parent.

fixtures observe real merge records and ancestry, and refusal checks compare the repository's

also checks that both incoming branches' files reached the worktree and index.
