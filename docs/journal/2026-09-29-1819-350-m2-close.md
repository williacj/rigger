## The load bar

The card's ordinary-load bar asks for the one-minute load average no higher than the host's
logical CPU count, read just before the run. The run read both in the same shell command that
started `npm test`, so no other work sat between the reading and the run. The load was 7.77
against 12 logical CPUs, measured by `sysctl -n vm.loadavg` and `sysctl -n hw.logicalcpu`.

## What taught us

The budget script prints one count per file and a package total, with no directory subtotal.
The per-directory figures the card asks for are sums of its per-file lines, taken with `awk`
over its output. Card revision 1 on #350 made that the item's wording, after Codex raised the
same gap on PR #406.
