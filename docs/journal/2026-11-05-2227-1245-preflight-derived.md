# Preflight excludes generated document rows from retired-ID citations

Card #1245's Table P is the acceptance for this development diagnostic. The change adds
`docs/derived/` to the citations filter in `scripts/preflight.mjs`. Source test lines still
own their citations, and the matrix generator still checks the derived document's bytes.

The P1 test uses the actual generator to change a matrix row containing an unchanged retired
decision in a test title. Before the filter change, `npm test -- --test-name-pattern='^P1 '
test/preflight.test.mjs` failed on `generated rows must not create retired citations`, reporting
the matrix row. The same command passed after the filter change. The saved outputs are
`1245-p1-red.log` and `1245-p1-green.log` in the dispatch's scratch directory.

The added tests cover each in-scope Table P row. P2 preserves exact source diagnostics. P3
requires one source diagnostic when an added title also reaches the matrix. P4 uses the real
generator's report to check a hand edit's matrix refusal. P5 preserves the spec, journal and
qualified historical-audit exemptions, including refusal without the historical qualification.
These are repository diagnostic assertions and introduce no product requirement claims.

Under P7, the cases met were nearby path spellings: `docs/derived-copy/note.md`,
`docs/derived.md` and `allowed/derived/note.md`. Their added retired citations remain refused.
The existing tests continue to cover unchanged source lines, deletions, renames, colored
patches, unusual path characters and failed historical-evidence qualifications. No other P7
case was met.

Measured at base `811b29b6a41c60192144f205e3685d46ce3091a4` on the dispatched Mac mini,
`npm ci` and the deterministic baseline passed. The baseline's runner reported tests=5030,
pass=5030 and fail=0; `uptime` reported one-minute loads of 5.38 before and 7.12 after.
The affected preflight file then reported tests=37, pass=37 and fail=0. Its start/end loads
were 13.09 and 17.25. The test diff adds lines without changing existing ones.
