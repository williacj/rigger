# Test tiers for #819

The deterministic tier now runs every non-host test file and refuses process starts outside the bounded `git` and `tar` calls. The host tier runs the listed process-starting files serially under the same stand-ins, reaper and temporary-directory cleanup. The two existing nested-suite tests use the host tier under G2. The list counts at the implementation commit are 37 host files, 36 awaiting split, and 50 converting.

The first implementation commit hook failed because its inherited PATH began at Git's internal `git-core` directory. The suite had linked the first `git` on PATH into its allowed directory, and that internal binary could not find `git-upload-pack`. A focused test reproduced the failure with `git-core` first on PATH; linking `/usr/bin/git` passed it. The final local full runs then passed: deterministic 2,429 passed, 0 failed; host 1,677 passed, 0 failed, 17 skipped.

Round 1 review found that named paths such as `./test/package.test.mjs` could cross tiers because the shell compared raw arguments while the worker normalized them. A single path function now gives the shell and worker the same repository-relative identity. A host run with options and no file names appends the host list, so Node never falls back to discovering unlisted tests in that mode. The parser test now reads reports from real nested suite runs, and the reaper source check runs as a process-free deterministic test.

Round 2 review found that a separate-word Node option value could make the shell miss the host list and that glob operands could cross either tier. At implementation commit `6a0e74721b731e9eaf36293971188b066dfde308`, the Node parent preload reads the file operands after Node parses options, adds the host list if there are none, and refuses glob operands before workers start. The worker enforces each tier's list independently of the operand shape. Canonical paths also settle case-varied names on the local file system. The new tests first failed on the round 2 counterexamples, then passed after the preload and worker changes. Local full runs passed: deterministic 2,431 of 2,431; host 1,686 passed, 17 skipped, 0 failed of 1,703.
