# A torn tail

Card #1393 (M8-17), acceptance revision `f4c44b53b653`, builds `ARCHITECTURE.md`, "A torn tail",
in `src/observation/sink.mjs`. The reader takes rule 3: a newline-terminated line that is not one
event, begins with `{`, and is one event from a later offset where `{"ts":"` begins, reads as that
event. "One event" is #1391's envelope check (the architect's ruling, 1293#6783691710). The sink's
hold now lets an event go only once the append of its whole line returns, and every later append,
the end's included, appends what is still held first.

Every reader call in the file, whether the read returns, recovers under rule 3 or refuses, also
asserts that the stream's bytes after the read equal those before (`R-RECORD-5`). The H rows that
read after a refused append go through the same check. Both round-1 judges on PR #1408 found that
the refusal rows asserted only the refusal. A reader that appended a byte or erased the stream
before refusing passed all of them.

The owner ruled the four residuals "A torn tail" names in M8-U17 (1293#6783843500), each as the
PM recommended:

- **Q1, plain JSONL.** The reader's rules define the stream, and `README.md` does not change.
- **Q2, naming a fragment.** The reader passes over a fragment without reporting it; the refused
  emit was already reported (`R-RECORD-9`).
- **Q3, one damage form misread.** A line beginning with `{` that ends in a whole event at a later
  `{"ts":"` is read as a fragment and an event. Accepted as a residual.
- **Q4, a late error after a whole line.** The held event's line is written again and read twice.
  Accepted as a residual; the sink is built against a short write.

The tear is injected in process: `node:fs`'s `appendFileSync` is replaced with one that appends half
the line through the real append and then throws `ENOSPC`, and `syncBuiltinESMExports` carries the
change to the sink, as `test/dispatch.test.mjs` does for `spawn`. An outright refusal is `chmod
0o555` on the state directory for H2b, and an `EIO` thrown before any byte for H4 and H6, where the
refusal must fall on one append among several. H6 reads standard error in process, by replacing
`writeSync`, which `writeWhole` writes through.
