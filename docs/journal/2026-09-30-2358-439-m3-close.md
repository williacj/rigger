An engine installed from an `npm pack` tarball of that SHA, outside every checkout, ran against a
fresh clone of this repository, also outside every checkout. Two throwaway cards went into Ready on

action was stated on #439 before it was taken.

The run needed no repeat: nothing failed for want of the network.

## What taught us

`npm ci` took under half a second in each workspace, because the package's only dependency was
already in the npm cache. The `vhs` step took 72 seconds, almost all of it Homebrew installing
`vhs` and what it depends on. The step's `brew list vhs ||` guard means a second run on this host
pays nothing.

Removing a workspace leaves the branch it checked out, and `AGENTS.md` reserves deleting a branch
to the owner. So the clean-up's last item, that neither card's derived branch exists in the target
clone, waited on the owner. The owner granted the deletion under O7, in
[#439's grant comment](https://github.com/williacj/rigger/issues/439#issuecomment-5925171023),
for those two branches in the scratch target clone only. A script then deleted `rigger-468` and
`rigger-469` there with `git branch -d`, and only `main` remains.
