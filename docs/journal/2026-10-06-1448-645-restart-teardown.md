# Restart teardown observes an exiting stand-in

The historical pre-push failure on #638 read card #10's restarted stand-in as `?E` at the final teardown check. The check read each recorded pid once. `test/process-fixtures.mjs`'s `sweep` stops when `running`'s `pgrep -f` finds no command line naming the test directory. A process in `E` can still appear in `ps` after that command line stops matching. The PM's revised acceptance on #645 permits this cause to be argued from the historical state, the sweep code, and passing instrumented runs when the intermittent window does not recur.

At `2de91a8a0dace3889d5a6aca7fdf6af2c118360b`, the new transient-state test failed with the existing message, `a process the test recorded is alive after its teardown`. The test supplied `?E` followed by absence and the one-read check rejected the first state. Its full output is `c645-red.log` in the card's scratch logs.

The last hook now waits until no recorded pid is living, bounded at 10,000 ms, then makes the same process and working-directory assertions. The wait uses `living`, so a zombie passes without waiting for signal 0 to stop reaching it. Tests exercise `?E` then gone, `Z`, and `T` then gone. A real `tail` outside the world's sweeps still makes the process assertion fail with its message at the bound; another real `tail` working under the world's directory still makes the working-directory assertion fail after the wait. Both are ended by their tests' teardown.

Twenty instrumented runs of the original affected file at the base passed. Each started with one-minute load at or below 24; `c645-probe-repeat-1.log` through `c645-probe-repeat-20.log` and matching event logs record their outputs. A later instrumented healthy run recorded the scratch sweep matching the restarted stand-in, sending SIGKILL, then `pgrep -f` finding no match before the check found the pid gone. Those runs did not reproduce the historical `?E`, so they support the mechanism without proving the exact kill timing of that failure. A no-load forcing of the kernel's exiting state cannot be made without delaying a kill, which the card excludes.

An instrumented full-suite probe failed at `test/never-stop.test.mjs:546`, expecting one `survivor.unended` event and receiving none. Its full output is `c645-probe-full2.log`. Card #615 tracks that separate failure.
