# #612 — mixed judges are carried under the card's number

**The judges travel to `reached` through a callback, as the maker's result already did.** #598
had `attempt` hand the maker's result to `work` through `kept` before L2 was asked about judges.
This card gives `judges` a `keep` of the same kind. Where a judge fails to hand back, `judges`
hands `keep` every judge L2 named, in L2's order, before it rejects. `work` puts that list on the
card's own entry in `reached`, under its number, whichever path claimed it. So the card's
rejection keeps the shape it had at the base, less its card-less `judges`. A refused release
wraps that rejection one level deeper, and leaves `reached` where it was.

**Each carried judge takes one of three shapes, and the pull's answer changes only where one
failed.** A judge that handed back is `{ role, outcome }`, as at the base. A judge that failed is
`{ role, failure }`, holding the very error the rejection names it with. A judge L2 withheld is `{
role, withheld }`. Where every judge hands back or is withheld, `judges` answers only those
dispatched, as at the base, so the existing judge tests read it unchanged.

**L3 does not know L2's words for a withholding, only what it handed L2.** L2's judge answer
withholds a judge by leaving it out, and records why in a `judge.withheld` event L3 never reads.
So `withheld` carries what L3 handed L2 that L2 withheld the judge for. That is L1's failure to
make the directory, or the step in the judge's `head` whose outcome L2 was handed last, with that
outcome. `once` still says why in its own words, which it kept from L2's `failed` as it already
did.

**`once` says a failed judge where L3 carried it, and nowhere else.** At the base a failed judge
was said among the failure's lines after every card. Now its card carries it, so it is said among
that card's judge lines in L2's order. The failure's lines then skip that one error, by identity.

**`run` keeps every settled pull's cards on its failure.** In two pulls at concurrency 1, the
first card's pull can settle while the second's fails. At the base, `run` then rejected with the
failed pulls alone, and the first card's judges were carried nowhere. Its failure now carries
every settled pull's cards as `reached`, as a pull's failure already did.

**A refused start under `run` refuses once.** `run` pulls a card again as soon as its slot frees,
and a card whose judge failed still owes that judge. With every start of it refused, the run never
drains. The two-pull tests refuse each judge's first start alone, as an engine's next pull would
find the record working again.
