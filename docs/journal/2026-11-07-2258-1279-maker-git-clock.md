# Maker git fixtures use their injected clock

Card #1279, acceptance revision `408e96bddb74`, defines completion. `D29` rule 4 requires
Rigger's code under a deterministic test to read only the clock the test injects, except
where `D30` allows otherwise. The maker-git file has no such exemption.

The fixture reuses `manualClock` from `test/clock-report-world.mjs`, with the inert `pause`
already used by other L0 fixtures. Its existing replacement map installs the clock and
restores its original property descriptor. The layout captures the original clock object
before installation and asserts its identity in teardown after the restoration hook.
Existing test bodies, assertions and requirement declarations remain unchanged.

Before edits, a search of JavaScript tests for `maker-git.test` and `maker-git-clock` found
no cross-file binding. The fixture call-site search found every dispatch path reaches
`layout`, directly or through `dispatched`, `scheduledMaker` or `scheduledJudge`.
The declaration-only test does not replace the clock.

Measured through the host-wide suite slot at base `eda9124c`, `npm ci` and `npm test`
exited zero: tests 5379, pass 5379, fail 0. `uptime` measured one-minute loads of 2.61
at start and 7.82 at end; `ps -U "$(id -u)" | wc -l` measured 614 user processes at start.

Before the fixture change, the named maker-git run on a scratch merge with PR #1254's
pinned head failed: tests 33, pass 1, fail 32. The timer guard refused `setTimeout`
at delays 300000 and 500. After injection, the named run passed both on the branch
and on that scratch merge: tests 33, pass 33, fail 0. Full outputs remain in the
dispatch scratch directory; final head-bound verification and mutation receipts belong
in the pull request body.

Route (b), passing a host through `workspaces()` in `src/`, is the recorded reversal.
It returns when a second bounded test file needs the same fix. This card changes no
production source and does not add the file to either transitional list.

No case encountered required a choice that the acceptance did not decide.
