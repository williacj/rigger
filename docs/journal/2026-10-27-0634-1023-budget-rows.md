# Budget rows: L3 1,000 and L5 1,300

The owner's [M7-U2](https://github.com/williacj/rigger/issues/1009#issuecomment-6434513387) item 8
ruled Q9: "L5's row goes 1,500 → 1,300 and L3's 800 → 1,000; the package total is unchanged".
This card changes those two rows of `ARCHITECTURE.md` "Budgets" and nothing else. The package
row stays 12,000, and the other rows still sum to it.

M7's clock triggers land in L3, which had little room left. The figures below are measured with
`node scripts/package-budget.mjs` at `ce205ad1bc87`, the commit that changes the two rows. The
script prints one line per file and a package total, and no per-layer figure. Each layer figure
here is therefore the sum of the per-file lines it prints under that layer's `src/` directory.

| Layer | Directory | Sum of per-file lines | Row before | Row after |
|---|---|---|---|---|
| L3 | `src/scheduling/` | 778 | 800 | 1,000 |
| L5 | `src/observation/` | 146 | 1,500 | 1,300 |

The L3 sum is `admission.mjs` 216, `lane.mjs` 97, `loop.mjs` 443 and `pull-order.mjs` 22. The L5
sum is `report.mjs` 65 and `sink.mjs` 81. The package total is 7,282 against 12,000. This card
changes no file under `src/`, so the same sums hold at `66e5b7c9`, its merge base with `main`,
and at the commit that adds this entry, which changes nothing else.

What would reverse the split is the one [the architect's r1 review](https://github.com/williacj/rigger/issues/1009#issuecomment-6433591635)
gave in Q9: "M7's L5 derivations passing roughly 1,000 lines".

CI checks only the package total, so no script or test reads the L3 or L5 row. The edit changes
the table and no script.
