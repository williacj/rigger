# Card 1506: a label for work made by hand

Under owner ruling M8-U143 (https://github.com/williacj/rigger/issues/1293#issuecomment-7186506788), this card proposes rows that let a project mark cards Rigger must not pull. The cause was Emend #98, pulled and escalated because a headless maker cannot write under `.claude/`.

The proposal is label-only. A card's paths cannot be known before a maker works on it: Emend #98 names its paths only in acceptance prose, the `Lands in` bullet is a filing convention no requirement has Rigger read, and the coordinator's own read during #1418's stop 2 found a card that names `.claude/` without writing there.

The rows stop a maker's attempt in every column, not only pulls from Ready, and leave a card's judges and merge alone outside Ready. Emend's rule is that such a card "is made by hand and judged by the engine", and its hand procedure moves the card to Review for the engine's judges. A rule that refused every column would have stopped that judging. One that refused Ready only would have left an unclaimed Coding card, or a rework round after `needs revision`, open to the same maker dispatch.

R-SCHED-41's table is left as it was. The template refusal is a new row, R-SCHED-55, so that R-SCHED-41 keeps its id. The R-FAIL-8 table gains one out row, which keeps R-FAIL-8's id, because no hand label refusal was ever an environment failure.
