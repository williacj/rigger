# Matrix host claims

Card #824 owns the finite list-read contract. The generator asks the target repository's suite
for host membership and marks those claims in the matrix. A separate heading names requirements
claimed only by host files. The ordinary no-test count still includes every claim, and a consumer
with no suite retains its previous behavior. With no host claims the document remains unchanged.

The [recorded owner decision](https://github.com/williacj/rigger/issues/824#issuecomment-6401698700)
selects a 5000ms direct-process timeout and SIGKILL on expiry. This is a selected policy, not a
measurement or a promise that return happens within exactly that time. Node waits for actual
exit. The list command has a 1MiB output budget and runs with its repository as working directory.
An independently surviving descendant retaining output remains outside this direct-process scope.

The implementation keeps `check` synchronous. A small `generate` entry point owns the same
check-before-write path the CLI uses, so a failed list read cannot overwrite the matrix. The
controlled tests supply documented and observed Node result shapes, including an output-limit
error carrying exit status zero; error classification precedes output parsing.

The unchanged-base observations at `a848408` used the original generator and the suite's own
list command. They measured fourteen host-only requirement IDs and retained the no-host document
bytes for the literal comparison fixture. The base count line and all gap rows remain comparison
inputs; the matrix is regenerated by its tool rather than edited by hand.

Development witness `native-development`, with source fingerprints in its retained receipt,
ran Node 26.12.0 on Linux under WSL and passed ten native tests. Its TERM-resistant direct-shell
case recorded readiness, survived a TERM probe, returned after about 5029ms including caller
startup, and was absent after the generator returned. That is an observation of this fixture,
not a supported-macOS result or a general containment guarantee. Every native failure preserved
the prior matrix bytes. Separate controlled tests cover all ten finite cells and preserve bytes
through the actual `generate` write path.

G2 adds the new native test to the suite's host list. G3 adds only its literal expected member
before the existing sort, retaining every earlier member and the exact assertion. G1's existing
matrix-test lines remain; the additional tests carry the new observations. Supported-macOS proof
still requires a prospectively admitted immutable source and complete original receipts.
