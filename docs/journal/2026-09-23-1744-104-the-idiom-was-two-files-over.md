# 2026-09-23 — The idiom was two files over

Card #31 fixed `key in rules` walking the prototype chain in `src/config/validate.mjs`. Three days later `src/cli/init.mjs` asked the same question by truthiness on an object literal, and `test/init.test.mjs` — that file's own test — was already calling `Object.hasOwn(PROVIDER_ASSETS, role.provider)` at the time. The idiom was in the repository, in the test beside the code, and the production code still departed from it. Nothing in the fix travelled with the reasoning that produced it, because the reasoning had been written only as a comment inside `validate.mjs` where no author of `init.mjs` would read it. The fix here carries that comment to the second site and names the first, so the next reader of either meets the argument rather than a bare `Object.hasOwn`.

A sweep is worth more than the fix when a defect has recurred, and it is worth running twice. The first pass was a grep, and its bracket class was wrong in extended regular expressions — `[^\]]` reads as "not a backslash" followed by a literal `]`, so it matched only single-character indices and reported `found[1]` while missing `PROVIDER_ASSETS[provider]`, the defect itself. The second pass blanked comments and string literals and then enumerated by construct; its first version blanked template literals whole and so hid `PLACEHOLDER[key]` inside a `${}` substitution. Each wrong pass reported a clean-looking result. A sweep that finds nothing is not evidence until the tool has been shown to find the thing already known to be there, and the known defect is the fixture that shows it.

The probe set being the runtime's rather than the author's changed the answer's shape. Asking `Object.getOwnPropertyNames(Object.prototype)` returned twelve names on node v24.18.0, and all twelve produced a fork path where `codex` was refused — `constructor` yielding `function Object() { [native code] }/a.md` and `__proto__` yielding `[object Object]/a.md`. A typed list would have asserted the same thing about the runtime that was current when it was typed. The same probe against `validate()` and the CLI verb table answered identically to a name that is absent, which is what ruled those two out as sites rather than a reading of their source.
