# 2026-09-23 — A fallback answered the safety question a weaker way

`R-SAFE-5` turns on which tree `doctor` compares, and asking git which repository a directory sits in is the whole reason a run from `<repo>/src` is compared as `<repo>`. Where git declined, `repoRoot` answered anyway and handed back the directory it had been given. Nothing looked wrong: the function was total, the fallback was one ternary, and the comment above it described the fallback as a feature. What it did was reinstate, on one path, exactly the comparison the test two functions down exists to refuse — and measured on the real bin, a target that is no repository reported `3 of 4 checks passed` with the runtime sitting inside the directory being checked. The review found it; nothing I had written could have. My own test asserted the asking, and the fallback is what happens when the asking fails, which is a different input.

The same shape cost the report twice over. `nodeVersion` read `package.json` as though it were always there, and `configValidity` read `.message` off whatever the consumer's config threw. Both were total for the input the author had in mind and both threw for the input the code actually receives, and in a file whose whole subject is a check that can say it could not look, a check that says so by throwing takes the other three lines with it. The second one is the instructive one: the first had already been found and fixed, its comment states the consequence in so many words, and the same defect was sitting eight functions below on the one input that file's own comment calls arbitrary consumer code. Fixing a defect is not the same as sweeping for it, and the sweep is what was skipped.

The lesson both share: where a function cannot answer, the caller decides, and a fallback inside the function takes that decision away silently. `repoRoot` now answers null and `doctor` refuses, because refusing one tree too many costs a consumer a message and refusing one too few costs them the runtime mid-run. What makes that reviewable is that the two answers are now in different places.

A mutation that survives is a finding, not a null result. The judge's seventh mutation — counting a check that could not be asked as passed — left all nineteen tests green, which said the third verdict's effect on the exit code was correct and defended by nothing. One edit stood between the suite and a `not asked` line above a zero exit, which is the precise thing this verb exists to prevent. The acceptance never named the state, so nobody owned proving it; the test that now does was written by applying the surviving mutation, watching it red, and reverting.
