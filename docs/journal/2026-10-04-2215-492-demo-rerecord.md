# #492: the demo shows `once` dispatching a maker

**Where the GIF comes from.** The tape needed no change: #486 had already given it, CI's grep and
the demo test the dispatching line. So the committed GIF is the `demo` artifact that CI's demo job
uploaded for main at `813b35d` (run 37237776993, vhs 0.11.0), copied unaltered. A recording made
on this host would match no run a judge can open, and vhs is not on every host (`D12`'s notes).
The GIF is not reproducible byte for byte from one run to the next, because the screen holds the
run's temporary directory. So the evidence is the named run, not "the head's run".

**What the alt text may claim.** The card holds the alt text to the final screen, `docs/demo.txt`.
That screen says the card and board, that the maker exited 0 and opened no pull request, the
workspace it ran in, and `exit 1`. It does not say the board is fake or the maker a stand-in, so
the alt text says neither, though both are true of the world the tape builds.

**Why it does not say provisioned.** The card first asked the alt text to say `once` provisions the
workspace, but `once` prints nothing for provisioning: the demo world's one step is `true`. That
claim could not be shown on the screen, so the two items conflicted. The PM ruled that the screen
governs, so the alt text says the maker ran "in its workspace" and stops there.
