# Responsibility for manual directories

Proposal [#848](https://github.com/williacj/rigger/issues/848) assigns each session responsibility for the worktrees and scratch clones it makes by hand. The [owner's approval](https://github.com/williacj/rigger/issues/848#issuecomment-6327255295) retained cleanup at hand-off or session end when the forge already holds the work.

The instruction belongs in `AGENTS.md` because it applies to every role. It distinguishes the session's own directories from another session's, and requires the owner before removing work the forge does not hold. Card #850 inserts the approved paragraph without changing engine cleanup or deleting any directory.
