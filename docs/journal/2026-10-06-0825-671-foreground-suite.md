# Card #671: keep the suite in the maker's session

In #495 run 1, Claude Code moved `npm test` to the background at its 120-second Bash default. The maker then ended its `-p` session before the command settled. Rigger correctly killed the survivor and withheld review because no pull request existed. The consumer settings now give Bash a 30-minute default and maximum, and the engineer prompt requires the maker to finish or report an in-flight command before ending its session.

The gated live test asks Claude Code to run a command with no tool timeout. With project `env` set to `10000`, its tool result reports 10 seconds. A guarded local mutation removing that entry reported 120 seconds and failed the same assertion. This shows project `env` is honored under the adapter's `--setting-sources project` flag on Claude Code 2.1.291.

The instruction pool was nearly full at the base, so the edited prompt shortens existing maker instructions while preserving their duties. The new stand-in test ties L0's child kill to L2's withheld review and the card's Coding column.
