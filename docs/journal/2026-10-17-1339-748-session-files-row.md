# Where a dispatched session's files land

M6-02 proposes `R-WORK-31` and its dimensions table, so that #629 has a ratified row to claim. The draft came from #748 at acceptance revision `92470be1b5ad`, with U4.5 and U4.6 written in.

`npm run check:paths` reads any backticked span shaped like a repository path as one. The draft's paths under Claude Code's configuration home, such as `projects/` and `history.jsonl`, failed it, because no such path exists in this repository. Writing the home as `<home>` and each path from it cleared the check. That form also keeps every row true when a consumer moves the home. Exempting the names in `doc-references.json` would have put a file outside the card's **Lands in**.

`~/.claude.json` sits beside the home, not under it, so the shared-file row names it as beside the home. "The session's directory" became "the directory the session runs in", the phrase `ARCHITECTURE.md` uses, because a judge's CLI runs in `main` and not in its dispatch's directory. "Once M6-20b lands" became "a role dispatched to answer an escalation", since a binding row should not name a card.
