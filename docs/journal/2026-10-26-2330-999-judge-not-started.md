# A judge's dispatch that never started

Done for #999 means its acceptance revision `88aca99116e1`. M6-01z (#964) merged through #968,
which added host rows to `R-FAIL-8`'s table for a judge's dispatch that never started. #968's body
found lines of "Failure model" that no longer held of that table, and sent them to this card,
M6-03o. [The architect's attack on #964](https://github.com/williacj/rigger/issues/964#issuecomment-6417592650), finding 7, bound an architect structure card to place the
failure: where L1 reports it, and how L3 hands it to L2.

[U72](https://github.com/williacj/rigger/issues/740#issuecomment-6419099911), rule 1, defines the
pair: the same judge's next dispatch for the card, failing for the same cause, is the card's second
attempt under the host class. The survival ruling in the architect's attack on this card, which
K96 records, settles where the first failure lives. It lives in the one call that dispatched the
judge, and it does not survive an invocation, because `R-STATE-4` and `R-STATE-1` bar persisting
it.

The placement follows the two precedents "Failure model" already held. A maker's second attempt
gets the first attempt's failure handed unread. The role an escalation goes to is retried alone
under the same routing comment. A judge's host failure is retried the same way: L3 runs step 4 for
that judge alone, under the same claim and slot, and hands L2 both outcomes. No placement needed
the first failure to survive an invocation, so nothing was escalated.

L1's report carries the provider, the agent file, the path or the variable a cause concerns, in
L1's own terms. L2 classes the report under a row and compares two reports. Boundary rule 2 is
unchanged, because "that a command never started" is L1's term, and what it names is set in
"Failure model".

The one new memory case is a judge's two dispatches that never started for different host causes,
where `R-FAIL-8`'s table has the card stop. A judge withheld on its next dispatch is already the
memory's row for judges L2 withheld.

M6-08g (#1000) is the change card whose tests claim `R-FAIL-8`'s judge rows, and it builds against
this placement. Its Table A row for a first failure and a next dispatch in different invocations
reads, under this placement, as a first failure with no hold.
