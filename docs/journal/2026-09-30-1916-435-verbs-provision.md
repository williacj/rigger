# #435 — the verbs pull through `loop`, and stop at the workspace

**The verb holds only what it resolves.** `once` resolves the worktree root against the guard's
top level, refuses a root in the package tree under `R-SAFE-5`, and awaits L1's workspace handle
before it builds `loop`. A topic git refuses therefore exits before any board read. Everything
else, the retry, the halt on a refused event and the step outcomes, was already L1's, L2's and
L3's. The verb only hands them the handle, the state directory and the provisioning steps.

**Shared worktree roots collide across tests.** Every existing verb world built its target with
`repositoryIn`, directly under `$TMPDIR`. The default root `../widgets-worktrees` would then be one
directory for every test in the run. A second test's `rigger-10` would meet the first test's
workspace, a worktree of another repository, and L1 would rightly refuse it. Each world's target
now lives in a directory of its own, with its bare `origin` beside it. The owner accepted this as
part of "gains a local bare origin".

**A test stub can model the tree too narrowly.** `test/worktrees.test.mjs:662` swaps L1's
workspace module for a stub that exports what `src/` imported from it at the base. The verb's new
import of `workspaceHandle` broke it. The first replacement I proposed and the owner granted,
`export const workspaceHandle = workspaces;`, made the stub's handle the adapter itself, and rule
10 then read the CLI as importing the adapter. The second, `export function workspaceHandle() {}`,
holds nothing of the adapter's. Both grants are on #435.

**A refusal of one event cannot be selected from outside the process.** The refused-`dispatch.end`
tests have the optional step move the stream aside and put a directory in its place. The sink then
refuses that end and every append after it. The stream as it stood is kept and read. The verb
level can show that nothing later started. The proof that L3 would not start the next step
without that later refusal is `loop.test.mjs`'s, with its stand-in sink.

**Re-firing on a freed slot hangs.** A mutation that had `run` call `loop.run()` never settled,
since a card stopped in Coding is pulled again as a redo, for ever. The tests could not reach a
verdict until the hung verbs were killed by hand. So every verb spawn in the new test file now
carries a 60-second SIGKILL bound.
