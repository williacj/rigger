**The two rule tests.** Both flagged the new live-run file, and both were right about it:
- `codex --version` was spawned with no environment named. Every spawn whose command arrives at run

  test builds goes through `test/git-repository.mjs`, which already had `worktreeAt` and
  `detachedWorktreeAt` for exactly this.

`~/.codex/auth.json`. This container has neither. So every live-run item stays unmet until the
owner's host runs `RIGGER_LIVE_CODEX=1 npm test -- test/provider-codex-live.test.mjs`. That run
includes the token-refresh observation. The owner's token expires 2026-10-06, by #473's reading.
