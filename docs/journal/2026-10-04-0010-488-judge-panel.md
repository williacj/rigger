**The three red decide tests were one cause: the ask after the settle.** The acceptance has L3
hand the facts L2's settle answered to L2's `decide` under the same claim. That ask is new, and
comes after the maker. `test/attempt.test.mjs` counts every ask its world's `decide` sees, and
scripts one by the number of outcomes it is handed, so it read the new ask as a second ask at the
pull. No grant row named those lines. The first proposal filtered the new ask out of the world's
count. The coordinator refused it, because it narrows what the tests count. The granted form
extends the expected counts, and asserts that the last ask carries exactly the settle's facts
after the settle ran. That needed the world to hand its stand-in the options L3 passes to
`decide`, which it had dropped. A test cannot prove an argument its harness throws away.

replaces `src/execution/workspace.mjs` with a stub naming its exports. `once` now imports
`judgeDirectoryHandle` from it, and the stub must name that too. This is the same kind of line
#555's grant table missed, and again it showed up only when the file ran.

which this Linux container lacks. So the test of a judge's leftover process in its `head` fails
