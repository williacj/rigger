before automatic teardown, hiding a premature teardown snapshot. The original R5 proof was incomplete.

readiness and a live recorded direct PID first. After that test's actual teardown, the parent
asserts the captured snapshot's readiness and ended-shell observation, then independently checks the PID is gone.

Restoring the original teardown made the same test pass. No existing teardown line changes are committed.

reply assertions, with both erroneous acceptance and erroneous rejection attacked. R5 now attacks both
