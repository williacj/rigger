# #476 — the exit test has to run the engine it is evidence for

**Two true statements left the exit run with no engine.** `D7`'s Notes make a milestone's exit
test the evidence that the new engine works. `D7` rule 1 and the build plan keep the installed
engine a release behind until the milestone closes. M4's exit run packs the SHA under test (the M4
draft's §6), so it could honour one statement only by breaking the other. Codex r5-1 on #467 found
the gap, and the owner ruled the answer in O21.

**The amendment adds a case, and moves no boundary.** The candidate engine runs one exit run from
its own tarball against its own clone. The engine that builds Rigger is still upgraded only at the
milestone close, to the closing commit. Rules 1 to 3 read exactly as before, so nothing a ratified
rule meant has changed. That is why the change amends `D7` rather than superseding it.

**The installation rule is restated as three parts, on purpose.** The acceptance asks the rule to
name them, and the exit run's separate clone is a part the build plan's own wording never needed.
