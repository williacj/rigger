# Card #802: the verdict contract

The README's verb list is the CLI contract. Card #802 adds `verdict` there and in `VERBS` while leaving `LANDED` alone, so the command reports that it is not yet implemented until M6-24 lands its behavior.

The existing `--help lists exactly the verbs the README lists, in that order and no others` test reads the README rather than a copied list. Adding the README line first made that test fail because `verdict` was absent from `--help`. Adding the `VERBS` entry made the focused CLI file green without changing a test line.

The Security text states the confirmation boundary and its limit: a session with the owner's credentials can post with `gh` or open its own terminal to confirm with `rigger verdict`. The gate cannot distinguish those acts from the owner's, as `D25` rule 2 records.
