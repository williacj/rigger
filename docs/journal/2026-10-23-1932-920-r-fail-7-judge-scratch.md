# Card 920: R-FAIL-7 classes a judge's scratch directory not made

[#920](https://github.com/williacj/rigger/issues/920) proposes the delta
[U43 and U44](https://github.com/williacj/rigger/issues/740#issuecomment-6377288414) rule on.
`R-FAIL-6`'s table classed a judge's scratch directory refused under `R-WORK-26`, but not one the
file system failed to make. The architect's third recheck of #871 found the gap (finding 8).

U43 classes the cell `out`, beside a judge's directory not made, so the judge row widens and its
outcome stays. The register's preamble decides the id: the edit moves a cell into scope, so the
row takes `R-FAIL-7`, and `R-FAIL-6` moves with its table unchanged to the retired register. The
16 test claims of `R-FAIL-6` retarget under the card's grant class G1.

What taught us: the second id move in one milestone was cheap because #875 left a pattern to
follow. The same script shape applied every edit, and each replacement asserted it matched exactly
once before anything was written.
