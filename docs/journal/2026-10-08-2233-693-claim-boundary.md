# A control can define a result class without proving credential exclusion

The first judge found that eight new credential-free tests stayed green when an independent mutation printed raw git failure reasons containing synthetic userinfo. Their `R-SAFE-1` declarations therefore claimed behavior those inputs could not exercise. The PM/card-author ruled that these are acceptance-only controls and authorized removing their eight new declarations while preserving their tests and assertions.

The declaration check failed on all eight before the edit and passed on all eight afterward. The repository generator rebuilt the test matrix: its `R-SAFE-1` row went from 21 references to 13, dropping exactly those eight controls. The credential-bearing references remain, and the affected init test file passes 51 of 51 tests. The generator's gap count remains 69 of 168 requirements.
