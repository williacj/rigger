# Card 871: review revisions

The continuing-fetch hold test must exercise two `FETCH_FAILED` outcomes. A workspace host failure can also be injected at L1's replace-rule check; a check that gives no answer remains `WORKSPACE_NOT_MADE`, so retry and hold tests must keep their two-attempt assertions. An answered check remains a card-local refusal. The tests now distinguish those paths without reading a failure message to classify it.

An answered maker scratch refusal carries the exact `R-WORK-27`, `R-WORK-28` or `R-WORK-29` condition. The test checks each condition against its own path and unchanged contents. The existing test titles name `SCRATCH_REFUSED`, matching the code their assertions already require.

A sink refusal while recording a timed-out `cat-file` remains `EVENT_REFUSED` through L0 and L1. L2 cannot make a retry decision from an unrecorded timeout event, so `fetchLineAt` preserves that code instead of mapping it to `FETCH_FAILED`.
