# Clock configuration and occurrences

Card #1077, acceptance revision `c7dedefa1c2b`, defines this work. The configuration now offers
clock declarations through the existing shape reader. `schedule(trigger, instant)` parses the
schedule used by validation and answers adjacent occurrences in epoch milliseconds. Its returned
`refusals` name invalid schedule keys; valid schedules also return `newest` and `next`, with null
where no occurrence exists in the supported time range.

Template selection and acceptance use L2's `kindOf` and `checkAcceptanceForm`. The label inventory
includes template labels after provider labels and before fixed labels. The architecture delta
is a proposal: the owner must ratify the fenced clock shape, its comment, the paragraph below it,
the acceptance sentence, and the Self-hosting validator path at the PR head.

The first shape test exposed a shared formatter that threw on BigInts. I stopped and posted
1077#6470917222. The author's revision permits the root-cause fix in `holdsNothing`, including
nonclock sites that previously threw there. The formatter keeps JSON's original rendering when
JSON answers, and uses `inspect` only when that rendering throws. C39's Symbol-in-kinds throw
remains outside this work.
