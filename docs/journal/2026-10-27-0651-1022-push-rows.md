# Push rows

[M7-U2](https://github.com/williacj/rigger/issues/1009#issuecomment-6434513387) item 4 has a
refused or timed-out push leave work running, and attaches a time bound to `R-RECORD-8`.
[The r1 review](https://github.com/williacj/rigger/issues/1009#issuecomment-6433591635)'s Q5 had
found that `R-RECORD-8`, as written, fails between a refused push and the next one that succeeds.
A bound changes what must be true, so `R-RECORD-8` is withdrawn and `R-RECORD-13` replaces it.

`R-RECORD-13` takes Q5's form, "as of each successful push … when that push started", and not
M7-U2's summary "by the next successful push". The summary is ambiguous for an event recorded while
a push is in flight, which the card's attack found as its finding 1. It also narrows "placed
anywhere else" to a copy Rigger places, in `R-SAFE-3`'s words, since no push refreshes a copy the
owner makes by hand.

[M7-U3](https://github.com/williacj/rigger/issues/1009#issuecomment-6440291524) item 2 has M7-31's
tests claim every new row, so this card adds no test and the matrix marks the six rows **gap**.
`R-RECORD-17` names no figure; M7-07 places the limit. `R-RECORD-18`, the exit status, is the PM's
proposal on `R-SCHED-17`'s precedent, and the owner rules on it at the marker.
