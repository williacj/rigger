# #451 — the Failure model cites R-WORK-13

**A resolving citation can still name a row that binds nothing.** #449 withdrew `R-WORK-11` for
`R-WORK-13` to `R-WORK-16`. The retired register keeps the old id allocated, so the reference
check stayed green while the Failure model pointed at a withdrawn row. Only reading the row the id
lands on shows that. A green `check:references` says the id exists, never that it still binds.

**Citing the lead row cites the whole rule.** `R-WORK-13` states when Rigger replaces a card's
workspace and fails the attempt otherwise. `R-WORK-14` to `R-WORK-16` each carry one condition of
it, as `R-GATE-5` to `R-GATE-8` do for `R-GATE-4`. The Failure model sentence names what the
replacement requires, so it cites the lead row and the continuation rows come with it. Listing all
four ids would restate the register's own structure in a document that does not own it.

**The structure did not move.** The sentence says where the replacement lives and that nothing
reads a workspace back. Ruling 9 narrowed which directories may be replaced, which is what must be
true of Rigger, and the register holds that. So the delta is the id alone, and no other line of
`ARCHITECTURE.md` changes.
