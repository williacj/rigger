ABOUTME: What a journal entry is, and how the file names in this directory order the entries.

# Journal

An entry records something learned or something that failed, dated, in as few lines as that
takes. It binds nothing — a rule that came out of an entry is written where rules live, and the
entry says what taught us. `AGENTS.md` holds when an entry is committed.

Each entry is its own file here, named `<date>-<time>-<card>-<slug>.md`: the date and time it
was written, the card that produced it, and a short form of its heading. Two things follow. A
card owns every name it writes, so two cards working at once never write one file and never
collide over one. And the names sort into reading order without being opened — oldest first
ascending, newest first descending — so no line inside any file has to carry that order.
