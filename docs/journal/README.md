ABOUTME: What a journal entry is, and how the file names in this directory order the entries.

# Journal

An entry records something learned or something that failed, dated, in as few lines as that
takes. It binds nothing — a rule that came out of an entry is written where rules live, and the
entry says what taught us. `AGENTS.md` holds when an entry is committed.

Each entry is its own file here, and `AGENTS.md`, "Version control", holds the name form. Its
parts are the date and time the entry was written, the card that produced it, and a short form
of the entry's heading.

Two properties follow from that form:

- A card owns every name it writes, so two cards working at once never write one file and never
  collide over one.
- The date and time are fixed width, so the names sort into reading order without being opened,
  oldest first ascending and newest first descending, and no line inside a file carries it.
