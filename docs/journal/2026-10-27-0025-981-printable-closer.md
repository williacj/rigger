# `once` and `run` print a closer through `printable`

`once.mjs` now names each closer through `closerLine` and an unreadable admission through
`unreadableAdmission`, so all four verbs name a closer in one form. L3 keeps its own message and
carries the entries its admission read answered as `unreadable` on the rejection, unescaped, by
the architect's placement ruling on #981: L3 imports nothing from `src/cli/`, and `printable` is a
property of a terminal line.

A judge withheld for its scratch directory reaches `judging` as L1's report that its dispatch did
not start (`NOT_STARTED`), where one withheld for its directory is L1's `WORKSPACE_NOT_MADE`. The
code picks the lead-in, and L1's reason follows it unchanged.

The bin names the consumer's state directory by its real path, `/private/var/...` on macOS, where
`TMPDIR` spells `/var/...`. The new tests spell it through `realpathSync.native` to match.

A test through the real bin makes a judge's scratch directory fail without failing the maker's.
It makes `<root>/scratch/rigger-10/reviewer` a directory nobody may list before the run. L1 then
cannot tell it holds no checkout, and reports `EACCES` with the path as `missing`.

The bin tests start processes, and the deterministic tier lets a test start only `git` and `tar`.
So they sit in `test/printable-closer-verbs.test.mjs`, on `test/suite.sh`'s host list. The L3 and
source tests stay in `test/printable-closer.test.mjs`, deterministic. The L3 test builds its loop
by hand, since `loop-world.mjs`'s world starts a stand-in agent.

The new tests first carried a third copy of the consumer fixture that `once.test.mjs` and
`run.test.mjs` each held: the repository, the board, the card factory, the refused card, the kinds
and the config. The architect blocked that under the Rule of Three. Under the coordinator's K98
grant (#740), the three now import it from `test/verb-consumer.mjs`, and no test body, assertion
or title changed. Every named test is the same before and after. The suite's total rises by one
because `node --test` books every `.mjs` under `test/` as a file entry, the new module included,
as it books `test/process-fixtures.mjs`.
