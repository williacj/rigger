# Card #1259: exiting command

`endNestedDescendant` now admits a dying read as defined by the card's Table N: the recorded `pid` and `birth`, the `E` flag after a run state other than `Z`, and `command` exactly `(`name`)`. A dying read earns no ending credit and no signal, and reading goes on to `Z`, `absent` or the existing observation bound.

The trace comes first in the branch, as its own commit, so the runs that measure the failure hold the merge base's refusals. Every run's private trace under `C615_EVIDENCE_ROOT` receives the same `identity` rows as the `nested.identity` records, for the abort case too. A passing run's records therefore stay readable, although the abort case emits no safe records (`nested.identity` is limited to the close case).

The signal block in the loop is wrapped by `if (!dying) {` without re-indenting it. Its lines fall outside the grant, and a `continue` before them would have needed a second copy of the yield that `control.turn` owns, so a dying read at the top of the loop reaches that yield through the same lines as every other read.

The safe record's `stat` keeps only a token whose first character is one of `D I R S T U W X Z t ?` and whose later characters are each one of `+ < > A E L N S s V W X l`, and writes `unrecognized` for any other, because the column is parsed as one `\S+` token and the card bars raw command text from these records. The raw token stays on the object `nestedProcessIdentity` returns.

## Cases met under row N11

Each stays as at the merge base.

| Case | What the harness does |
|---|---|
| A refused read, whether malformed, errored or aborted | Its record has no `stat`, because no column was parsed and that record's line is outside the grant |
| A read whose `?E` line has an empty `command` | The parse fails, and it refuses with `cannot observe recorded descendant`. No run was seen to produce it |
| A recorded path whose first word is cut by a space, or a name `ps` would shorten | The name differs from `ps`'s, so the read refuses as another command |
| An injected observer's read with no `stat` | It is not a dying read, so a changed command refuses |
| The final read at L9968, in the dying form | `state` says `dying`, `commandMatch` says `mismatch` because that line is outside the grant, and `a recorded descendant remains live` fails. The loop ends only at `Z` or `absent`, so it was not reached |
