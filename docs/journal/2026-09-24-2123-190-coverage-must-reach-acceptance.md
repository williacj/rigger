# Card #190: coverage must reach acceptance

The skill already bound each card's acceptance to its own scope. That did not show whether all
parts of a larger piece of work reached any card. A map to acceptance items, rather than card
titles, makes a missing part visible before filing.

An outside-system change whose undo is unclear needs two distinct bars. The maker states the
action before taking it, and proves behaviour on a fake wherever a fake can prove it. Separating
them lets a judge rule on both timing and evidence.

The first test run failed because `init` compares the live skill to its template copy. Both copies
carry the guidance so a new repository receives the same instructions.
