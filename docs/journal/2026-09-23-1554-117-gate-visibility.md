# Text the gate cannot decide from

The [spike report](../spikes/reserved-git-indirection.md) measured reserved Git commands executed by Bash from values, files and another interpreter while the hook permitted their payloads. Refusing every unresolved form closed the measured rows in a throwaway variant, but also refused ordinary commands in each class and left the substitution family open. A small line-count delta did not express that cost.
