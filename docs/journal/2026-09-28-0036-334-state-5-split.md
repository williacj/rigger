  24 items met.

  - **The plan.** Its three citations of the row move to the new ids.

  - `R-STATE-9`: "killed outright" also covers a fault signal sent with `kill`, which Rigger

  - `R-STATE-16`: only an ending Rigger caused, or saw was by a signal. A trapped outside signal
    followed by exit 0 is an ordinary exit;
  - `R-STATE-10` defers to `R-STATE-11`, which also covers an unreadable record and ends a group
    later only once it confirms the group.

  `R-STATE-13` names standard error as its observer again, and `R-STATE-6`'s colon moves onto the
  rule.
- **The README** now says Rigger ends the processes left in its groups unless it is itself killed
  outright. The round-1 wording promised more than the rows require.

## What we learned

- **A lint count of 0 is not a rule-4 verdict.** `spec-style-lint` reads rules 1 and 2 only. Rule 4
  reached the row only because the judges read it.
- **Proving a row wholly true is the test for its words.** Reading each clause against the cards
  that must prove it (#336 to #349) found E1 to E5. None of them was visible from the row alone.
- **A row is only as true as the observation that separates its cases.** Round 2's
  `R-STATE-16` demanded one result for a command Rigger never saw signalled, and `R-STATE-15`
  demanded the opposite for the same wait status. Only Rigger's own observation can separate the
  two cases, so the row now says what Rigger saw.
- **The split costs ids but buys judgeable rows.** Each row now holds one condition or one
  obligation, and #349 declares tests against each id rather than against clauses of one id.
