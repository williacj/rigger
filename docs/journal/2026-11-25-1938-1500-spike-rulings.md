## What we learned

- **Each row was added beside the sentences it qualifies, never inside one.** Rule 8's "that entry" and rule 11's opening
  stop keep their meaning only if no new sentence lands between them and what they refer to, so the additions close each
  rule rather than interrupt it.
- **The card's wording was used as written.** Each row's sentence carries the actors and conditions the owner ruled, so a
  paraphrase would have been a second reading of the ruling.
