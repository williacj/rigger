# 2026-09-25 — The acceptance skill states the admitted form

At the card's base, the skill told an author to write plain bullets in the issue body, but did
not name the heading the form check reads. Its Given/When/Then examples were loose bullets. An
author copying that shape into a card could leave it with no acceptance the check counts.

`R-CARD-12` and its continuation rows own the parsing rule. The skill now points there and names
the consequences for an author: a different heading, task-list items, or fenced bullets can
leave a card with no counted items. Its example is a complete acceptance section displayed in a
Markdown fence. The live skill and the init template carry the same bytes.
