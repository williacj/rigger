# The pattern has both shapes

Node v21.7.3's `utils.js` defines four `kPatterns` entries and joins them into one `kDefaultPattern`; `runner.js` passes that string to the glob. The competing descriptions were of different stages, not different source versions. The runner relation on a sixteen-name fixture matched the budget check on Windows Node 20, 22, 23, 24, 25 and 26. Node 21.7.3 had six charged files the runner executed and one file the runner skipped but the check excluded. The existing code record already named those directions; the new measurements extend its version list.

The package's `>=20` engine range has no upper bound. The seven published majors now each have a named measurement, but future majors remain unproved until measured. That difference belongs in the pull request's evidence, not in a claim that the current check covers versions that have not shipped.
