# Proof handoff for Test quality

[#615](https://github.com/williacj/rigger/issues/615) took repeated acceptance and proof rounds because an item depended on the card's own judge and gate, retained originals were not bounded before attempts, and reviewer mutation work became visible late. The [O258](https://github.com/williacj/rigger/issues/467#issuecomment-6156528582) and [O259](https://github.com/williacj/rigger/issues/467#issuecomment-6156862189) owner rulings applied to the candidate they named. Neither gives other attempts proof credit.

[#839](https://github.com/williacj/rigger/issues/839) changes prospective instructions. Card authors now keep acceptance independent of its delivery controls and bound any offered historical proof. Makers check the branch and provider route, keep the pull request description current, and preserve each retained-original attempt's outcome. Reviewers inventory proof claims at first handoff and record denied checks with zero proof credit. The existing independent verdict and reviewer-owned checks remain required unless the owner grants an exact exception for the current candidate.

Each live instruction moves with its `init` template, as the existing parity tests require. This change edits no gate, config, source, other card’s acceptance, owner ruling, or private original. It provides a handoff rule for future Test quality work, including #697; it does not validate #615's lost or ungated attempts or grant #699 clearance.
