# Forge reads and repository writes

The comment read needs a permission lookup per distinct author. GitHub's comment author association does not answer whether that author can write; the adapter now keeps the lookup within one facts read and returns the six fields the next card consumes. A deleted account has no login and needs no permission request.

The check read leaves status creator and pinned integration separate. A check run's App can be compared with a rule's pin, but the status creator is returned as GitHub gives it. The merge endpoint makes the final ruling on a pinned status.

The repository write runner accepts only a merge commit guarded by an expected head SHA and a comment on a pull request. A pull-request read precedes either operation and the merge endpoint checks the SHA again, closing the race between the read and the write.

The boundary test's live source-tree check reported a rule 5 violation when a repository-write import was temporarily added to `src/cli/once.mjs`. The file was restored byte for byte after the mutation.
