# 2026-09-25 — A restart reads the board and redoes whatever was interrupted

**Most of the restart was already built, so this card mostly proves it.** #221's pull order
already offers unclaimed Coding and Review cards as redos, ahead of Ready ones. #228's loop
already skips the claim move for a redo. Ruling 1 says a restart is a tick with an empty claim
set, with no cold-start mode. So a second `loop()` over the same fake board already redid the
interrupted cards. Only L2's freshness was missing from `src/`.

**Freshness is now L2's input, not a filter placed in front of L2.** Before this card, tests
wrapped `nextAction` and answered `ignore` for fresh cards themselves. Now `nextAction` takes
`{ columns, fresh }`. It applies `fresh` only to a card in the `coding` or `review` column. With
no `fresh` given, no card is fresh, which is production's answer until M5 reads markers (ruling 1,
U10). `plan` passes nothing, so it still lists every redo. A `fresh` given with no `columns` is
refused rather than silently read for no card. The loop and pull-order tests now inject
freshness through this input.

**The loop harness moved to `test/loop-world.mjs`.** The restart tests and one child process
need the same wiring as `test/loop.test.mjs`: the fake board, L2, a held dispatch and the sink.
One copy is imported by all three rather than repeated.

**A stopped run is one whose held dispatches are never released.** Nothing more of that engine
reaches the board. The second engine shares only the fake board with it: it has a new loop, a new
L2, a new sink and a new freshness set.

**Only one of `R-STATE-4`'s three permitted things exists yet.** That one is the event stream.
Admission state and process-group ids have no code writing them, so the state-directory test
permits `events.jsonl` alone. The card that first writes either of the other two widens that list.

**The deleted-state-directory test has no mutation that reds it.** No code reads the state
directory, so the test cannot fail today. It guards against a later change that does.

**The restart tests passed as soon as they were written.** The only red was L2's fresh case in
`test/next-action.test.mjs`, which came before the code. Guarded mutations show that each other
restart test discriminates, and the pull request lists them.
