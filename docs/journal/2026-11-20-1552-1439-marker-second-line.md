# The Codex judge's marker block goes on the verdict's second line

The coordinator's Codex judge prompt told a judge to end its verdict with the gate's marker block, while `parseMarker` in `src/workflow/marker.mjs` reads a block only where it opens on a comment's second line. A judge that followed the prompt literally posted a marker the gate never read: the Codex reviewer's verdict on PR #1436 (1436#7051260376) probed its own comment and got `{"state":"none"}`. The gate's own printed instruction already said "Its second line opens this block"; the prompt overrode it.

The prompt now puts the block directly under the heading, the rest of the verdict after the block's closing fence, and says to fill every placeholder, `coverage` included, to leave out `coverageReason` and `toSound` where they do not apply, and to copy the block without the run log's per-line prefix. That prefix was read from `gh run view 44823296567 -R williacj/rigger --log` on 2026-11-20: each line opens with the job name, a tab, the step name, a tab and a timestamp.

The new test in `test/coordinator-launchers.test.mjs` is a harness diagnostic with no `// proves` line, as the card states. It runs the real `codex-judge.sh` against the stub `codex`, lays out a verdict in the order the prompt's "## Post" section names its parts, and asks `parseMarker` whether the gate reads the block. It also refuses a sentence about the marker block that names another position for it. It fails on the prompt's text at `bbaa0429` and passes at the head. Its D29 rule 11 declaration names wiring as its reason, and `test/marker.test.mjs`'s "a marker block not directly under the comment's first line is no marker" as the deterministic test of the gate's read.

In round 1 both Codex judges found the first version tied to wording: it required the phrase "second line" in every placement sentence and the phrase "closing fence", so equivalent wording such as "line two of the comment" failed it. They also found it lacked its D29 rule 11 declaration. Asking the gate's parse about the prompt's order replaced both phrase checks.

The differential test against the rebuilt source copy sets aside the changed "## Post" lines through a `placed` function called from `kept`, under the card's grant G1. The card's author widened G1 to cover the doc comment above `sourceCopy`, base lines 254 to 256, and this work rewrote lines 255 and 256 to say the comparison also sets aside the lines `placed` names.
